# نهر — برنامج تمكين الموظفين

موقع تعريفي عربي RTL لبرنامج نهر B2B لتدريب الذكاء الاصطناعي للشركات وتمكين الموظفين وتطوير أنظمة العمل الداخلية.

## مبادئ النسخة الجديدة

- لا روابط تحميل داخلية ظاهرة للزوار.
- لا قصص نجاح وهمية أو صور placeholder عامة.
- لا أزرار وهمية؛ كل CTA يذهب لنموذج واضح.
- تصميم بسيط رسمي رملي/بيج، بدون neon gradients أو bento مبالغ.
- SEO أساسي من أول نسخة: title, meta description, canonical, Open Graph, JSON-LD, sitemap, robots.
- Accessibility: labels حقيقية، focus واضح، semantic sections، ولا يوجد horizontal overflow.

## التطوير

```bash
npm run build
npm run check
```

المخرجات في `public/` للنشر على Vercel.
